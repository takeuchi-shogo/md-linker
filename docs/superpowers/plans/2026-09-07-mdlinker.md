# mdlinker v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `mdlinker check` で Markdown の Repository 参照整合を静的検査し、text/json/github で診断を返す Go CLI を作る。

**Architecture:** CLI は薄く、`app.Check` が config → scan → parse → engine → report を組む。Rule は `FileSystem` と `Document` だけを見る。Path 解決と GitHub 互換アンカーは共通処理に寄せる。

**Tech Stack:** Go 1.22+, goldmark, yaml.v3, 標準 flag

**Spec:** `docs/specs/2026-09-07-mdlinker-design.md`

## Global Constraints

- module path は `github.com/takeuchi-shogo/md-linker`
- バイナリ名は `mdlinker`。設定ファイルは `.mdlinker.yaml`
- Rule ID は `MDL001` `MDL002` `MDL003` `MDL004` `MDL006` `MDL007`。`MDL005` は欠番
- 読み取り専用。ネットワークアクセスなし。AI なし。`--fix` なし
- exit 0 = 成功または warning のみ / 1 = error 診断あり / 2 = 実行エラー
- `mdlinker` 単体はヘルプ（exit 0）。`mdlinker check` の対象省略時は `.`
- Rule から `os.Stat` を直接呼ばない。goldmark AST を Rule に漏らさない
- 診断は path, line, column, rule で安定ソートする
- コミットはユーザーが明示したときだけ行う（この計画の Commit ステップはスキップ可）

### Task 7: MDL001 / MDL004 / MDL007 の path 系 Rule

**Files:**
- Create: `internal/rules/mdl001.go`

**Interfaces:**
- Consumes: `repository.Resolve`, `repository.FileSystem`
- Produces: 各 Rule 実装

MDL001:

- 外部 scheme は無視
- dest 空で fragment のみは無視
- `Outside` は無視
- `fs.Exists` が false なら診断
- ファイルでもディレクトリでも存在すれば OK

MDL004:

- 画像 dest に同じ解決を適用
- 存在しなければ診断

MDL007:

- Exists は true だが、親ディレクトリの `ReadDir` 名と case が違う
- 実在しないパスは MDL001/004 に任せ、MDL007 は出さない

- [ ] **Step 1: テスト**

```go
func TestMDL001BrokenLink(t *testing.T) {
    fs := repository.NewMemFS()

    doc := &engine.Document{
        Path: "README.md",
        Links: []engine.Link{{Dest: "./docs/setup.md", Line: 2, Column: 5}},
    }
    diags := rules.MDL001{}.Check(ctx, doc)
    if len(diags) != 1 || diags[0].RuleID != "MDL001" {
        t.Fatalf("%+v", diags)
    }
}

func TestMDL001HTTPIgnored(t *testing.T) {
    ctx := engine.NewContext(".", repository.NewMemFS())
    doc := &engine.Document{Path: "README.md", Links: []engine.Link{{Dest: "https://example.com"}}}
    if diags := rules.MDL001{}.Check(ctx, doc); len(diags) != 0 {
        t.Fatalf("%+v", diags)
    }
}

func TestMDL007CaseMismatch(t *testing.T) {
    fs := repository.NewMemFS()
    fs.WriteFile("Docs/Setup.md", []byte("x"))
    ctx := engine.NewContext(".", fs)
    doc := &engine.Document{Path: "README.md", Links: []engine.Link{{Dest: "./docs/setup.md", Line: 1, Column: 1}}}
    diags := rules.MDL007{}.Check(ctx, doc)
    if len(diags) != 1 || diags[0].RuleID != "MDL007" {
        t.Fatalf("%+v", diags)
    }
}
```

MemFS は case-sensitive に実名を保持する。`Exists` は case-insensitive で探し、実名は `ReadDir` で返す、という実装にすると MDL007 のテストが安定する。
